# The repository's license

- **Date:** 26 November 2026
- **Status:** Accepted
- **Decided by:** William, from three options with a recommended answer
- **Settles:** the CLAUDE.md "Still open" item "Furqaan's agreement to reuse his code in the submission, and how he's credited". Extends `2026-11-20-scope-and-team.md`, which isn't edited

## Context

The repository had no license file, and no package declared one. The results contract, `contracts/src/ForemanResults.sol`, already carries `SPDX-License-Identifier: MIT`, and that source is verified on Sourcify (exact match, 21 November 2026), so its label can't change.

Furqaan Nabi wrote `packages/contract`, `packages/chain-bnb` and the archive backfill before he left on 20 November 2026 (13 of the repository's commits). Foreman reuses that code, and the README credits him by name.

## Decisions

### 1. MIT for the whole repository

`LICENSE` holds the MIT text, and every `package.json` declares `"license": "MIT"`. This matches the verified contract's label.

*Rejected:*
- **Apache-2.0.** It adds a patent grant that nothing here needs, and the repository would no longer match the verified contract's MIT label.
- **No license.** Judges could read the code but nobody could reuse it, which is unusual for a hackathon entry and contradicts the contract's label.

### 2. William decides; Furqaan's agreement isn't sought

William leads the project and decides its license. Furqaan isn't asked to agree.

The copyright line names both authors, "Chukwunonso Ikeji and Furqaan Nabi". This states who wrote the code; it gives neither author a say over the project. The README's Credits section keeps naming the packages Furqaan built.

## Consequences

- Copyright in code generally stays with whoever wrote it unless it is assigned. Furqaan's packages are released under MIT here without his written agreement. That is a known gap, accepted for the submission.
- CLAUDE.md's "Still open" item about Furqaan is struck, pointing here.
